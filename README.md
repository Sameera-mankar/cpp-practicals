## Mini Project: Library Management System

The Library Management System is a console-based C++ application developed to manage library book records.

### Features
- Add new books.
- Search for books using Book ID.
- Display book records.
- Issue and return books.
- Store and retrieve records using file handling.
- Handle invalid operations using exception handling.

### Concepts Used
- Classes and Objects
- Encapsulation
- Inheritance
- Polymorphism
- STL Vector
- Exception Handling
- File Handling using fstream
